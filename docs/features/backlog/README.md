# F-BACKLOG: Deferred Capability Governance

## Purpose

Make conscious exclusions visible so future planning can distinguish MVP scope from attractive but deferred product ideas.

## MVP Scope

- Track deferred capabilities that are intentionally outside the first implementation.
- Keep deferred items linked to requirement IDs.
- Record reconsideration triggers where known.
- Prevent backlog features from being treated as hidden MVP commitments.

## Out of Scope / Backlog

- Implementing deferred capabilities.
- Full roadmap estimation.
- Priority scoring beyond the requirement registry's current priority labels.
